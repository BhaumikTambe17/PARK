SMARTPARK - SIMPLE VS CODE WEBSITE

1. Extract this folder.
2. Open the folder in VS Code.
3. Install the VS Code extension "Live Server" (optional but recommended).
4. Right-click index.html -> Open with Live Server.
5. Register a new account or use the demo account:
   Email: demo@smartpark.com
   Password: 123456
6. Use Parking -> select a slot -> enter vehicle/date/time -> confirm booking.
7. My Bookings shows the logged-in user's bookings.
8. admin.html shows a simple owner/admin dashboard.

IMPORTANT:
This version is a front-end demo. User accounts and bookings are stored in the browser's localStorage, so they are NOT shared between different devices/users.
For a real deployed system where the owner receives registrations and bookings from every user, add a backend/database such as Firebase, Supabase, Node.js + Express + MySQL/MongoDB, etc.
